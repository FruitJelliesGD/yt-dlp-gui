# yt-dlp-gui UI增强设计文档

## [S1] 问题

当前yt-dlp-gui界面仅支持基本的yt-dlp选项（URL、保存路径、格式ID、Cookies），无法满足高级用户对yt-dlp丰富功能的需求。用户需要记住复杂的命令行参数，降低了工具的易用性。

## [S2] 解决方案概述

采用**渐进式披露**设计模式：
1. 保持基础界面简洁，仅显示核心功能
2. 添加可折叠的高级选项面板，包含6个选项卡
3. 支持自定义指令输入，允许用户添加不在预设中的参数
4. 改进格式选择功能，显示友好的分辨率和音频质量信息
5. **记忆功能**：保存用户输入过的选项和下载历史

## [S3] 基础区域设计

### 界面元素
- **视频链接输入框**：支持粘贴URL
- **保存路径选择**：文件夹选择对话框
- **格式ID输入**：默认值`bv*+ba/b`，支持手动输入
- **Cookies文件选择**：支持导入浏览器Cookies
- **操作按钮**：
  - 查看可用格式(-F)
  - 开始下载

### 功能说明
- 保持现有功能不变
- 添加格式ID下拉选择功能（见[S4]）

## [S3.1] 任务界面重构

### 任务列表改进
- **暂停/取消按钮**：每个任务添加暂停和取消按钮
- **ETA显示**：显示预计剩余时间
- **可点击链接**：点击URL跳转到原视频页面

### 任务状态管理
- **暂停功能**：暂停下载进程，保留已下载部分
- **取消功能**：停止下载，清理临时文件
- **恢复功能**：从暂停点继续下载

### 界面布局
- **任务卡片**：每个任务显示为卡片形式
- **状态图标**：不同状态显示不同图标
- **进度信息**：进度条、速度、ETA

### 技术实现
- **进程控制**：使用进程信号控制yt-dlp
- **状态保存**：保存下载状态到临时文件
- **链接处理**：使用浏览器打开视频链接

## [S4] 格式选择功能

### 实现方式
1. 用户点击"查看可用格式(-F)"按钮
2. 程序调用`yt-dlp -F <url>`命令
3. 解析输出，提取格式信息
4. 在格式ID输入框旁显示下拉按钮
5. 用户可从列表中选择格式

### 格式列表显示
- **视频格式**：分辨率、编码、码率、帧率
- **音频格式**：质量、编码、码率、采样率
- **格式ID**：清晰显示在右侧

### 快速选择按钮
- 最佳画质（默认）
- 1080p / 720p 预设
- 仅音频
- 自定义组合

## [S5] 高级选项面板

### 面板结构
- **可折叠**：点击"高级选项"按钮展开/折叠
- **6个选项卡**：下载、网络、字幕、播放列表、后处理、认证

### 下载选项卡
- 输出模板：`%(title)s.%(ext)s`
- 限制速度：默认无限制
- 重试次数：默认3次
- 片段线程数：默认1
- 复选框：强制重新下载、忽略错误

### 网络选项卡
- 代理设置
- 超时时间
- 连接限制
- IPv6偏好

### 字幕选项卡
- 字幕语言选择
- 字幕格式
- 自动翻译
- 嵌入字幕

### 播放列表选项卡
- 播放列表下载
- 排序方式
- 下载限制
- 播放列表项限制

### 后处理选项卡
- 文件转换
- 缩略图下载
- 元数据写入
- 文件名模板

### 认证选项卡
- 用户名/密码
- OAuth令牌
- 两步验证
- netrc文件

## [S6] 自定义指令框

### 功能
- 允许用户输入不在预设选项中的yt-dlp参数
- 多个参数用空格分隔
- 提供语法验证功能
- 支持清空输入

### 界面
- 等宽字体显示
- 验证语法按钮
- 清空按钮

## [S7] 技术实现要点

### 格式解析
- 正则表达式解析yt-dlp -F输出
- 提取格式ID、分辨率、编码、码率、帧率等信息
- 构建格式对象列表
- 支持视频和音频格式分类显示

### 状态管理
- 使用ObservableCollection管理格式列表
- 绑定下拉列表到格式数据
- 支持选择事件

### 界面更新
- 动态显示/隐藏下拉列表
- 格式选择后更新输入框
- 保持现有下载逻辑不变

### 任务界面技术实现
- **暂停机制**：发送SIGSTOP信号给yt-dlp进程
- **取消机制**：发送SIGTERM信号给yt-dlp进程
- **ETA计算**：基于已下载大小和当前速度计算
- **链接处理**：使用Process.Start打开默认浏览器

### 错误处理
- 格式解析失败时显示错误信息
- 网络错误时提示用户
- 自定义指令语法错误时高亮显示
- 任务暂停/取消失败时提示用户

## [S9] 部署考虑

### 向后兼容
- 保持现有功能不变

## [S10] 更新功能

### 自动更新检查
- **启动时检查**：程序启动时自动检查GitHub release
- **手动检查**：用户可手动触发更新检查
- **版本比较**：比较当前版本与最新版本

### 更新流程
1. **检查更新**：调用GitHub API获取最新release信息
2. **显示更新**：弹出更新提示，显示新版本信息
3. **用户确认**：用户同意后开始下载
4. **下载更新**：下载新版本exe文件
5. **备份旧版本**：备份当前版本到临时目录
6. **替换文件**：关闭程序后替换旧文件
7. **重启程序**：自动启动新版本

### 界面元素
- **更新按钮**：在设置界面添加"检查更新"按钮
- **更新提示**：检测到新版本时显示提示
- **更新进度**：显示下载进度
- **更新日志**：显示新版本更新内容

### 技术实现
- **GitHub API**：使用GitHub Releases API
- **版本格式**：支持语义化版本号
- **下载管理**：支持断点续传
- **原子更新**：确保更新过程的原子性

### 错误处理
- **网络错误**：更新失败时提示用户
- **权限错误**：文件替换失败时提示用户
- **回滚机制**：更新失败时自动回滚到旧版本

## [S11] 记忆功能

### 用户选项记忆
- **保存路径**：记住上次使用的保存路径
- **格式偏好**：记住用户常用的格式选择
- **高级选项**：记住用户设置的高级选项值
- **自定义指令**：保存用户输入过的自定义参数

### 下载历史记录
- **视频链接**：保存已下载的视频URL
- **下载状态**：记录下载成功/失败状态
- **下载时间**：记录下载时间戳
- **文件信息**：记录下载文件名、大小等

### 界面元素
- **历史记录按钮**：在主界面添加"历史记录"按钮
- **下拉菜单**：显示最近下载的视频列表
- **清除功能**：支持清除历史记录

### 数据存储
- **本地文件**：使用JSON格式存储在用户目录
- **配置分离**：选项和历史分开存储
- **隐私保护**：不上传任何用户数据
