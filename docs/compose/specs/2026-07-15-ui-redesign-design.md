# yt-dlp-gui UI现代化重设计

## [S1] 问题

当前UI存在以下不统一问题：
- 文字大小不一致（有11px、12px、未设置）
- 输入框高度不一致（有30px、未设置）
- 按钮大小不一致（有26px、36px，宽度不统一）
- 标签样式不一致（有些加粗，有些不加粗）
- Padding不一致

## [S2] 设计目标

采用VS Code风格的现代化深色界面，实现：
1. 统一的视觉风格
2. 统一的文字大小
3. 统一的输入框高度
4. 统一的按钮样式
5. 统一的标签样式
